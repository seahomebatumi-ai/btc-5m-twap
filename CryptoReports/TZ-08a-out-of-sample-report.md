- **By `tau = 10`:** `S_t` = 77298.589184144885, so `state` = +1.9609, and `sigma_live` had risen

reconstruction error.

**Why the value is infinite.**

- `pfair.phi` is the project's only `Phi`: `0.5 * (1 + erf(z / sqrt(2)))`. In IEEE doubles it
  returns exactly `0.0` once `z` is below about −8.37. The lower tail cancels to nothing, although
  the true `Phi(−10.819)` is about 1e-27 and representable as a double.
- `tz07a-variance-time.log_likelihood` maps that log of zero to `-inf` explicitly, at lines 276–277.
- So the code's likelihood is `-inf` for every `lambda` below **1.292** on the corrected estimator
  and below **1.791** on the uncorrected one. At `lambda = 1` it is `-inf`.
- TZ-07a's in-sample run on the TZ-06 set had a finite ratio at `tau = 30`, 4.325. This is the
  first time it has happened.
